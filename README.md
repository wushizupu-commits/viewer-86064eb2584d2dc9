# 族谱访问统计查看页

这是一个独立部署的个人查看页。族谱网站不提供入口，但本页仍是公开静态页面：没有登录认证，知道链接的人都可以访问。页面的 `noindex,nofollow,noarchive` 和 `robots.txt` 仅用于提示爬虫，不提供访问控制；GitHub Pages 项目子目录内的 `robots.txt` 也不能替代域名根目录的爬虫规则。

## 查询方式

- 只使用 `GET https://busuanzi.9420.ltd/api` 查询现有计数，打开和刷新本页不会上报访问量。
- `x-bsz-referer` 固定为 `https://wushizupu-commits.github.io/zongpu/` 下的七个归一化栏目网址，与本页部署地址无关。
- 不读取或保存访客标识，不读取浏览器存储，不携带身份令牌或跨站凭据。
- 提供域名累计浏览量、估算访客数及七个栏目计数。公共服务的可用性、去重准确性和数据保留不作保证。

## 部署与预览

将本目录作为独立仓库根目录，在 GitHub Pages 中选择相应分支的根目录发布即可；不需要构建步骤或账号密钥。项目地址可以包含任意子目录，样式与脚本均使用相对路径。

本地使用任意静态 HTTP 服务打开 `index.html`；直接用 `file://` 打开会保留页面但停用查询。检查网络面板时，应只看到七个固定栏目对应的 GET 数据查询；浏览器可能另行发送跨域预检 OPTIONS。刷新按钮会重新查询同样七个栏目。
